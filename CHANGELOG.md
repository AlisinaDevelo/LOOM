# Changelog

This project is pre-alpha. Entries describe repository changes and do not constitute release
promises.

## Unreleased

### Added

- A local evidence-first ingestion and retrieval slice for selected UTF-8 text and Markdown files.
- SQLite canonical records with FTS5 passage search, BLAKE3 content hashes, and exact text anchors.
- CLI and Tauri UI entry points, a rights-clean retrieval smoke fixture, and project governance
  documentation.
- Backend-owned folder selection, stable no-follow reads, missing-source reconciliation,
  version/hash-bound source opening, and structured collision-free evidence highlighting.

See [ROADMAP.md](docs/ROADMAP.md) for planned work and [EVALUATION.md](docs/EVALUATION.md) for the
limits of the current fixture.
