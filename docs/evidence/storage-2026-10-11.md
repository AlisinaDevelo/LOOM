## Checks and limits

`npm ci` and `npm run check` pass: 61 UI, 15 extension and 6 tooling tests, lint, typecheck and
production build. All eight privacy-control tests pass. Workspace/all-target Clippy with
`--locked -- -D warnings` and Rust formatting pass.

`cargo test --workspace --locked --no-fail-fast` ran all targets: **423 passed, 1 failed across
38 result groups**. The sole failure is the existing
`jobs::tests::persistent_retrieval_during_native_queued_ocr`, which reports provider refusal
instead of completed jobs. [#338](https://github.com/AlisinaDevelo/LOOM/issues/338) remains open;
this is not a passing workspace or an OCR mitigation.

The foundation CLI run has 4,139.199 ms summed command wall time and maximum reported resident
memory 20,676,608 bytes. The killed writer was terminated after cursor 1/96 and resumed the same
run for the remaining 95 units; no killed-process RSS is claimed. Measurements cover this small
fixture, not whole-library responsiveness or power loss. The calibrated macOS denial profile
rejects a loopback connection that succeeds without it. CLI execution works under denial; this
does not measure attempted connections or cover GUI/framework/external-viewer traffic.
